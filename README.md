# Odin-recipes

## Description
This project is a recipe website that consists of a mainindex page which has links to multiple recipes.

## Skills Demonstrated
- How to create a repo on Github and connect to a local machine using git

- Creation of html pages and implementation of appropiate headers and text elements to establish a hierarchy for web browsers to read and interpret for users

- Implementation of images and links to navigate to different pages on the website

- How to write meaningful commit messages
